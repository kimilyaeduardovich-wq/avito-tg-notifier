# Ресепшн+ — кликабельный UI-прототип

Имитация по [`docs/resepshn-tech-spec.md`](../docs/resepshn-tech-spec.md).  
**Без API, без очередей, без реальных каналов.**

## Открыть

```bash
open prototype/index.html
```

Жёсткое обновление после правок: **Cmd+Shift+R**.

## Что имитируется

| Экран | По ТЗ |
|---|---|
| Инбокс | Фильтры, стадии cold/warm/hot/booked, ожидание, упущенная сумма |
| Карточка | Переписка + разбор (rules/llm) + коды причин + 3 подсказки + ответ + запись |
| Аналитика | Метрики с формулами, причины, рейтинг admin_score |
| Записи на день | Статусы, напоминания 24ч/2ч, неявка |
| Настройки | Услуги, мастера, роли, лимит ИИ |
| Каналы | TG/VK/MAX/виджет/WABA/IG OAuth; QR личного WA/TG — запрещены |
| Публичная запись | Услуга → мастер → слот → согласие 152-ФЗ |
| Стенд | Вставка переписки → «очередь разбора» |

Эмодзи в UI нет (требование ТЗ).
